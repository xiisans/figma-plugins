# 西无 — 重命名

用于批量重命名当前选中的 Figma 画板及修改文本，支持“快速命名”“选择替换”“文本命名”和“数字命名”四种模式，默认打开快速命名。

## 功能

- 按画布从上到下、从左到右的顺序重命名当前选择。
- 用基础名称组合数字序列、字母序列。
- 数字与字母片段按点击“添加”的顺序拼接。
- 对现有名称执行区分大小写的全文字面替换。
- 文本命名自动识别选中图层本身及所有后代中的 Text 图层，包括画板、分组、组件和实例内的任意层级文本；重叠选区自动去重，非文本节点不参与文本修改。
- 文本查找区分大小写，按字面匹配全部替换；仅输入查找文本表示删除匹配字符串，仅输入替换文本表示覆盖整个文本内容。两项均为空时不执行。
- 文本命名可在替换后的文本末尾追加数字序列；支持 1-32 位前导零及升序、降序，也可不填写替换规则而单独使用数字后缀。
- 数字命名按画布顺序将所有识别到的文本内容替换为数字；通过起始值、正整数步长和升降序控制序列，升序逐项相加，降序逐项相减。
- 文本模式实时预览替换后的内容；勾选“同步更改图层名称”时，按替换后的完整内容计数（Unicode 字符数）：不超过 12 个字符使用内容作为图层名，超过 12 个字符命名为 `text`。未匹配的图层保持不变。
- 同步勾选默认开启，取消后只修改文本内容，保留原图层名，包括 Figma 原本自动命名的文本图层。
- 修改文本前加载所有涉及的字体；存在缺失字体或加载失败时不执行本次修改。
- 实时预览最多 12 个结果（3 列、4 行），每次规则变化前重新读取当前选区内容。
- 使用 Figma 主题变量自动适配亮色、暗色模式。
- 画板名称与图层面板名称是同一个节点属性，会自动同步更新。

插件不会修改 Figma 项目文件名称，也不会发起网络请求。

## 本地开发

```bash
npm install
npm run check
```

然后在 Figma 桌面端打开：

1. `Plugins` → `Development` → `Import plugin from manifest...`
2. 选择本目录中的 `manifest.json`。
3. 选择若干 Frame、Section、Component 或 Component Set 后运行插件。
4. 修改文本时，选中文本图层或包含文本的任意图层并切换到“文本命名”，预览和执行均包含所有后代文本图层。

## 常用命令

```bash
npm run build      # 生成 dist/code.js 和 dist/ui.html
npm run typecheck  # TypeScript 类型检查
npm test           # 运行命名核心单元测试
npm run check      # 依次执行类型检查、测试和构建
```
