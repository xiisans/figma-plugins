# 插件色彩通用规范
#### 1.颜色
- 主色-默认状态：#4567FF
- 主色-悬浮状态：#5271FF
- 正向反馈：#4567FF，需要颜色搭配时，根据该颜色对应的色系进行搭配
- 警告色-默认状态：#E18E00
- 警告色-悬浮状态：#F59A00
- 错误色-默认状态：#EF4343
- 错误色-悬浮状态：#EF4D4D
- 禁用色：根据亮暗模式适配，灰色系颜色
- 面板背景色：跟随figma插件颜色以及亮暗模式适配
#### 2.布局
- 面板宽度：360px
- 边框圆角：2px, 4px，根据容器大小确定
- 侧边距：对齐 Figma 顶部的插件头
- 内边距：0px, 2px, 4px, 6px, 8px, 12px, 16px, 20px, 24px
#### 3.基础元素
- 一级按钮：高度36px，字体大小13px，字重500
- 二级按钮：高度32px，字体大小12px，字重500
- 输入框：高度36px，字体大小12px，字重400
#### 4.字体
- 一级标题：12px，字重500
- 二级标题：12px，字重400，字体颜色弱于一级标题
- 正文：12px
#### 5.图标
- 资源地址：https://feathericons.com/
- 裁切盒大小和粗细：viewBox: 24px, Stroke width: 2px
- 实际页面使用大小：12px, 16px, 24px, 32px, 48px
#### 6.模式
- 根据插件的 UI 模式进行适配，以上有明确颜色色值的都不改，其他的颜色色值根据模式进行适配
#### 7.滚动条
- 尺寸：8px
- 颜色：较弱的灰色
- 去掉滚动条两端的按钮 -webkit-scrollbar-button
