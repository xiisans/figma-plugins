# 插件色彩通用规范
#### 1.颜色
- 主色-默认状态：#4567FF
- 主色-悬浮状态：#5271FF
- 正向反馈：#4567FF，需要颜色搭配时，根据该颜色对应的色系进行搭配
- 警告色-默认状态：#F49B00
- 警告色-悬浮状态：#FFA100
- 错误色-默认状态：#EF4343
- 错误色-悬浮状态：#EF4D4D
- 禁用色：根据亮暗模式适配，灰色系颜色
#### 2.布局
- 面板宽度：360px
- 面板高度：480px
- 边框圆角：2px, 4px, 8px, 根据容器大小确定
- 侧边距：对齐 Figma 顶部的插件头
- 内边距：0px, 2px, 4px, 6px, 8px, 12px, 16px, 20px, 24px, 28px, 32px, 40px, 48px
#### 3.字体
- 一级标题：14px，加粗
- 二级标题：14px，字体颜色弱于一级标题
- 正文：12px
#### 4.图标
- 资源地址：https://feathericons.com/
- 裁切盒大小和粗细：Size: 24px, Stroke width: 1.5px
- 使用大小：12px, 16px, 24px, 32px, 48px
#### 5.模式
- 根据插件的 UI 模式进行适配，以上有明确颜色色值的都不改，其他的颜色色值根据模式进行适配
#### 6.插件头 LOGO
- 资源位置："./logo"
