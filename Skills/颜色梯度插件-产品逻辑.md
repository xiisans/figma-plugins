# 颜色梯度插件-产品逻辑

#### 一、产品基础信息

- 插件名称：“西无 — 颜色梯度”
- 产品定位：面向UI设计师的智能色板生成插件，基于用户选中的任意颜色，一键生成标准化实色梯度、透明度梯度色板，支持行业主流OKLCH/HSL双色彩模式、自定义梯度分布规则，可直接输出Figma官方颜色变量/可视化色板画板，适配全套UI设计规范。
- 核心能力：选中单色 → 智能计算梯度 → 两种生成形式（变量/画板）→ 适配亮暗模式、组件配色、系统色板搭建

#### 二、整体功能架构

**插件核心分为两大独立梯度模式，用户可自由切换：**
1. 实色梯度（无透明度，标准UI色阶）
2. 透明梯度（纯色透明渐变，适配遮罩/悬浮/弱提示场景）

#### 三、核心功能详细规则

**（一）实色梯度模式【核心重点】**
1. 基础规则
- 色彩计算模式：支持 OKLCH / HSL 手动切换（默认推荐OKLCH）
- 明度取值范围：固定 L值 98 ~ 6，所有梯度统一L值从大到小递减排序（浅→深）
- 可选梯度步数：10步 / 20步 二选一
- 可选分布规则：均匀分布 / 目标居中 二选一
1. 两种分布算法精准规则
- 均匀分布（通用模式）
以用户选中的基准色为参考，在 L=98 ~ L=6 全域区间内，根据选择的步数，平均均分明度差值，生成均匀过渡的实色梯度。
- 目标居中（设计常用主次色居中规则，核心定制逻辑）
将用户选中的基准色作为核心目标色，固定落在梯度中间位置，上下区间步数均分固定，严格遵循以下规则：
  - 选择10步梯度：目标色固定在第5步
    - 浅区间（L98 → 目标色L值）：5步梯度
    - 深区间（目标色L值 → L6）：6步梯度
  - 选择20步梯度：目标色固定在第10步
    - 浅区间（L98 → 目标色L值）：10步梯度
    - 深区间（目标色L值 → L6）：11步梯度
    - 核心逻辑：保证品牌主色居中，浅色层级、深色层级独立细分，符合UI设计视觉层级规范。

**（二）透明梯度模式**
1. 基础规则
- 固定基于用户选中基准色，色相/明度不变，仅改变透明度Alpha值
- 无OKLCH/HSL模式切换，统一原生透明度计算
2. 梯度步数与区间规则
- 10步梯度：Alpha 10% ~ 100%，递增步长10%
- 20步梯度：Alpha 5% ~ 100%，递增步长5%
排序规则：透明度从低到高（淡→浓），最终输出展示/命名统一适配规范。

#### 四、生成输出规则（变量 / 画板 双模式）

**两种梯度模式、两种步数，均支持 生成变量 和 生成画板 两种输出方式，规则统一。**

1. 生成Figma颜色变量（核心输出）
前置输入项
用户点击「生成变量」前，需手动填写：变量集合名、变量分组名（支持自定义输入）
变量命名规则（固定）
- 10步梯度：变量名依次为 10、20、30 ... 100（共10个，对应L值降序）
- 20步梯度：变量名依次为 10、20、30 ... 200（共20个，对应L值降序）
变量排序规则
严格按照 L值从大到小（浅→深） 顺序生成变量，匹配命名序号，完全贴合UI色板阅读习惯。

2. 生成可视化画板（预览/复用输出）
画板样式固定规则
- 单色色块尺寸：固定 120px * 120px
- 色块间距：固定 0px 无缝拼接
- 排列方式：L值降序，从左到右依次排列（浅→深）
- 生成位置：自动在用户当前选中元素的下方生成画板
画板命名规则（与变量完全对齐）
- 10步梯度：色块名称依次为 10~100
- 20步梯度：色块名称依次为 10~200

#### 五、插件UI面板结构（极简交互）

1. 模式切换区：实色梯度 / 透明梯度 切换Tab
2. 实色梯度配置区：色彩模式切换（OKLCH/HSL）+ 步数选择（10/20）+ 分布模式选择（均匀/居中）
3. 透明梯度配置区：步数选择（10/20）
4. 变量配置区：集合名输入框、分组名输入框
5. 功能按钮区：【生成变量】、【生成画板】两个核心按钮

#### 六、核心技术实现方案

- 色彩计算核心
  - OKLCH：采用标准OKLCH色彩空间插值算法（人眼均匀明度过渡，无脏色、偏色），固定H色相不变，仅动态计算L明度、微调C色度
  - HSL：标准HSL环形插值，固定色相，均分明度梯度
  - 透明度梯度：基于基准色固定色相明度，线性插值Alpha值
- 居中算法实现：单独封装专属计算函数，区分10/20步，拆分上下区间，精准匹配5/6、10/11步固定分配规则
- Figma API能力：调用官方变量创建API、画板/矩形创建API、元素定位API
- 排序逻辑：所有梯度生成后统一按L值降序重排，保证命名、展示、变量顺序一致

#### 七、开发验收标准（必过）

1. 实色梯度OKLCH/HSL切换正常，L值严格限定98~6递减
2. 均匀分布、目标居中两种算法逻辑完全符合定制步数分配规则
3. 透明梯度10/20步、5%/10%步长精准无误
4. 生成变量可正常在Figma变量面板展示，命名、分组、集合生效
5. 生成画板尺寸、间距、排列、位置、命名完全匹配规范
6. 所有梯度色值过渡自然，无断层、无溢色、无错乱排序
