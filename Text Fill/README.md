# 西无 — 文本填充

一个离线运行的 Figma 文本批量填充插件。插件会递归查找当前选中对象及其后代中的文本节点，按画布从上到下、同一行从左到右的顺序填充。

## 开发

环境要求：Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

开发预览默认运行在 `http://127.0.0.1:5173`。浏览器预览会模拟 8 个文本节点，用于检查界面和生成结果；它不会修改 Figma 画布。

## 构建与测试

```bash
npm test
npm run test:ui
npm run build
```

构建产物位于 `dist/`：

- `dist/code.js`：Figma 插件主线程
- `dist/index.html`：内联后的单文件 UI

需要持续监听源码并重建插件时，运行：

```bash
npm run watch
```

## 导入 Figma

1. 先运行 `npm run build`。
2. 在 Figma Desktop 打开 `Plugins > Development > Import plugin from manifest...`。
3. 选择项目根目录中的 `manifest.json`。
4. 选择画布对象后运行插件。

插件面板固定为 360×440。所有姓名、地址、段落等示例数据均内置，不访问网络。锁定节点、不可编辑实例、缺失字体或字体加载失败的节点会被跳过，并在执行结果中计数。

## 填充规则

- 快速填充支持姓名、昵称、性别、QQ 号码、Email、地址、数字、序号、日期、时间、手机、年龄和段落。
- 自定义填充忽略空行；文本不足时按输入顺序循环，直到填满所有目标，文本过多时忽略多余内容。
- 勾选随机填充后，每轮重新打乱有效文本顺序，循环填满所有目标。
- 日期在本地系统当前年份内生成，再按设置升序或降序排列。
- 画布位置的同一行判断使用 4px 容差。
